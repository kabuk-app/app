# Coverage exceptions

Index: [`../../AGENTS.md`](../../AGENTS.md).

Vitest enforces 100% on everything under `src/`. These are the only parts outside it.

| What | Why | Covered by |
| --- | --- | --- |
| `src-tauri/src/lib.rs`, `main.rs` | Tauri entry points and window management. No logic worth a unit test; the splash timing decision is a pure function in `src/lib/splash.ts`. | CI desktop build matrix compiles it; a real launch is the smoke test. A scenario test against the packaged app is still to do. |
| `src-tauri/gen/` (Android) | Generated by `tauri android init`, not committed. | CI Android debug build. |

`cargo llvm-cov --fail-under-lines 100` is not wired up for `src-tauri` yet. Add it as soon as
the crate has logic outside Tauri glue.
